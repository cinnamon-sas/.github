# Cinnamon

**Conversaciones y negocio, en un solo lugar.**

Cinnamon es una plataforma en la nube para pymes: une la atención al cliente y la administración del negocio en una sola sesión.

</div>

## Qué hacemos

**Cinnamon Chat** reúne WhatsApp, Instagram, Messenger, TikTok, Telegram y el chat del sitio web en una sola bandeja, con todo el historial de cada cliente y un mismo equipo atendiendo todos los canales.

**Cinnamon ERP** administra clientes, productos, inventario, proveedores, cotizaciones, órdenes, facturas y pagos.

Como Chat y ERP comparten la misma sesión y los mismos datos, lo que se habla en el chat se convierte en una orden sin volver a escribirlo.
